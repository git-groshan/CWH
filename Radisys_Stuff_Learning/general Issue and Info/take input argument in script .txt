To take input from the user in a Bash script, you can use the `read` command. Here's a simple example:

### 📝 Example Bash Script

```bash
#!/bin/bash

echo "Enter your name:"
read name

echo "Hello, $name!"
```

### ➕ With prompt on the same line:

```bash
#!/bin/bash

read -p "Enter your name: " name
echo "Hello, $name!"
```

### 📥 With default value:

```bash
#!/bin/bash

read -p "Enter your age (default is 25): " age
age=${age:-25}
echo "You are $age years old."
```

### 🛑 With yes/no check:

```bash
#!/bin/bash

read -p "Do you want to continue? (y/n): " answer
case "$answer" in
    [yY]|[yY][eE][sS]) echo "Continuing..." ;;
    [nN]|[nN][oO]) echo "Exiting..."; exit 1 ;;
    *) echo "Invalid input. Please enter y or n."; exit 1 ;;
esac
```

To take a **password input** from the user in a Bash script (without showing the typed characters), use the `read -s` option:

### 🔒 Example: Silent Password Input

```bash
#!/bin/bash

read -sp "Enter your password: " password
echo  # move to a new line after input
echo "Password has been received."
```

### ✅ With confirmation (verify both entries match):

```bash
#!/bin/bash

read -sp "Enter your password: " pass1
echo
read -sp "Confirm your password: " pass2
echo

if [ "$pass1" = "$pass2" ]; then
    echo "Passwords match. Proceeding..."
else
    echo "Passwords do not match. Try again."
    exit 1
fi
```

This ensures secure and user-friendly password entry in shell scripts.


VALIDATE IPV4  ADDRESS

To validate whether a user-input IP address is **valid** in a Bash script, you can use a regular expression.

### ✅ Example: Validate IPv4 Address Input in Bash

```bash
#!/bin/bash

read -p "Enter an IP address: " ip

# Regular expression for IPv4
ip_regex="^([0-9]{1,3}\.){3}[0-9]{1,3}$"

if [[ $ip =~ $ip_regex ]]; then
    # Now check each octet is <= 255
    IFS='.' read -r o1 o2 o3 o4 <<< "$ip"
    if (( o1 <= 255 && o2 <= 255 && o3 <= 255 && o4 <= 255 )); then
        echo "Valid IP address"
    else
        echo "Invalid IP: Octets must be <= 255"
    fi
else
    echo "Invalid IP format"
fi
```

### 🔍 Explanation:

* First, the regex checks the **format** (e.g. `1.2.3.4`).
* Then, the script ensures that each **octet is between 0 and 255**.

VALIDATE IPV6  ADDRESS

Here’s a **Bash script** that can validate both **IPv4** and **IPv6** addresses using regular expressions and basic logic.

---

### ✅ Bash Script to Validate IPv4 and IPv6

```bash
#!/bin/bash

read -p "Enter an IP address (IPv4 or IPv6): " ip

# Regex for IPv4
ipv4_regex="^([0-9]{1,3}\.){3}[0-9]{1,3}$"

# Regex for IPv6 (simplified but valid for most practical inputs)
ipv6_regex="^([0-9a-fA-F]{1,4}:){1,7}[0-9a-fA-F]{1,4}$"

# Validate IPv4
if [[ $ip =~ $ipv4_regex ]]; then
    IFS='.' read -r o1 o2 o3 o4 <<< "$ip"
    if (( o1 <= 255 && o2 <= 255 && o3 <= 255 && o4 <= 255 )); then
        echo "Valid IPv4 address"
        exit 0
    else
        echo "Invalid IPv4: Octets must be <= 255"
        exit 1
    fi

# Validate IPv6
elif [[ $ip =~ $ipv6_regex ]]; then
    echo "Valid IPv6 address"
    exit 0
else
    echo "Invalid IP address format"
    exit 1
fi
```

---

### 🔍 Notes:

* This IPv6 regex supports full IPv6 like `2001:0db8:85a3:0000:0000:8a2e:0370:7334`
* It **does not** support compressed forms like `::1` or `2001:db8::1`. If you need full RFC 4291 compliance (with `::`), we can add a more complex pattern or use tools like `ipcalc` or `sipcalc`.
