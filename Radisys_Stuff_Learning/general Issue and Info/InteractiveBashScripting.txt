Creating an interactive bash script that takes inputs from the user is simple! You can use the `read` command to prompt the user for input during script execution.

---

### **Basic Example**
Here’s a basic interactive script:

```bash
#!/bin/bash

# Prompt the user for their name
echo "Enter your name:"
read name

# Prompt the user for their age
echo "Enter your age:"
read age

# Print the input back to the user
echo "Hello, $name! You are $age years old."
```

---

### **Advanced Example: With Options**
If you want to guide the user with choices, you can use a menu:

```bash
#!/bin/bash

echo "Choose an option:"
echo "1. Display date"
echo "2. Show current directory"
echo "3. Exit"
read -p "Enter your choice (1/2/3): " choice

case $choice in
    1) echo "Today's date is: $(date)";;
    2) echo "You are in: $(pwd)";;
    3) echo "Goodbye!"; exit 0;;
    *) echo "Invalid choice!";;
esac
```

---

### **Features for Enhanced Interaction**
1. **Default Values:**
   Provide default values if the user doesn't input anything:
   ```bash
   echo "Enter your name (default: Guest):"
   read name
   name=${name:-Guest}
   echo "Hello, $name!"
   ```

2. **Yes/No Confirmation:**
   Use a loop to ensure valid input:
   ```bash
   while true; do
       read -p "Do you want to continue? (y/n): " yn
       case $yn in
           [Yy]*) echo "Continuing..."; break;;
           [Nn]*) echo "Exiting..."; exit 0;;
           *) echo "Please answer yes or no.";;
       esac
   done
   ```

3. **Multiple Inputs on One Line:**
   Read multiple inputs separated by space:
   ```bash
   echo "Enter your first name and last name:"
   read first_name last_name
   echo "Hello, $first_name $last_name!"
   ```

4. **Hidden Input (e.g., Passwords):**
   Use the `-s` option to hide user input:
   ```bash
   read -sp "Enter your password: " password
   echo
   echo "Password received."
   ```

---

### **Example: Combining Everything**
Here’s a more comprehensive interactive script:
```bash
#!/bin/bash

echo "Welcome to the interactive script!"

# Get user details
read -p "Enter your name: " name
read -p "Enter your favorite programming language: " language

# Confirmation with a default choice
read -p "Are you sure? (y/n, default: y): " confirm
confirm=${confirm:-y}

if [[ $confirm == "y" || $confirm == "Y" ]]; then
    echo "Thanks, $name! You love $language."
else
    echo "Okay, let's try again."
fi
```

---

### **Running the Script**
1. Save the script to a file (e.g., `interactive.sh`).
2. Make it executable:
   ```bash
   chmod +x interactive.sh
   ```
3. Run the script:
   ```bash
   ./interactive.sh
   ```
